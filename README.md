# KAIROS

> Zenith, a warrior of limitless power, exists for exactly 30 minutes.

2D action-RPG roguelite in **Godot 4.5**. Launch-and-chase combat, open-dimension powerleveling, and a life clock that is also your health.

- `GDD.md`: what and why
- `BUILD_BRIEF.md`: how Claude Code builds it, in order, with proofs
- `DECISIONS.md`: decision log

## Run
Open the folder in Godot 4.5, or: `godot --path .`

## Check
`./tools/check.sh` (import, headless boot, tests, bot playthrough)

The earlier web prototype lives on the `web-slice-archive` branch (rules reference only).
